# 🎯 Quiz Game

A feature-rich **console-based Quiz Game** developed in **C++**. The game provides an engaging learning experience with multiple quiz categories, three difficulty levels, countdown timers, lifelines, random question generation, and a score tracking system.

---

## ✨ Features

- 🎮 Interactive console interface
- 📚 Five quiz categories
  - Science
  - History
  - Sports
  - Computer
  - IQ
- 🎯 Three difficulty levels
  - Easy
  - Medium
  - Hard
- ⏳ Countdown timer for every question
- 🎲 Random question generation
- 🛟 Lifeline system
  - Remove two wrong options
  - Skip one question
- 🏆 Score calculation system
- 🔥 Bonus points for consecutive correct answers
- 💾 File handling for storing scores
- 📋 View previous quiz results
- 🎨 Colorful terminal output

- Object-Oriented Programming (OOP)

## 🎮 Gameplay

1. Start the game.
2. Enter your name and date.
3. Select a quiz category.
4. Choose a difficulty level.
5. Answer each question before the timer expires.
6. Use lifelines wisely.
7. Complete the quiz.
8. Your score is automatically saved.
9. View previous scores anytime.

---

## 📊 Scoring System

| Action | Points |
|---------|--------|
| Easy Correct | +10 |
| Medium Correct | +15 |
| Hard Correct | +25 |
| Easy Wrong | -2 |
| Medium Wrong | -3 |
| Hard Wrong | -5 |
| 3 Consecutive Correct | +5 Bonus |
| 5 Consecutive Correct | +15 Bonus |
